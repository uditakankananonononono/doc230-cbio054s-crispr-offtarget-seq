# CBIO054-S "partial: 3D core blocked (no coordinates in public encoded data)"
Parent CBIO054 "3D-Aware CRISPR Off-Target Prediction". This repo covers ONLY a sequence-only off-target benchmark (5 directions). The public encoded datasets carry no genomic coordinates, so no Hi-C, chromatin or other 3D/epigenomic feature is used or claimed anywhere in this repo. Preregistered and committed before any model is scored.
Data: CIRCLE-seq (Tsai 2017; 584,949 sgRNA/DNA pairs, 10 guides, 7,371 labelled off-targets) as primary; Kleinstiver 2015 GUIDE-seq (95,829 pairs, 5 guides, 54 positives) and Listgarten 2018 GUIDE-seq (383,463 pairs, 22 guides, 56 positives) as external transfer sets. Source http://bio.info.uqam.ca/data/ via dagrate/public_data_crisprCas9; hashes in data_manifest.
Encoding: 24-position aligned pair (23-nt sets get a leading gap), 6-symbol alphabet A,C,G,T,N,gap, case ignored.
Models: B1 mismatch count (fewer mismatches = more likely off-target). B2 L2 logistic regression on per-position mismatch/gap indicators. M small Conv1d CNN on the one-hot pair (3 epochs). Training uses all positives + 10x random negatives; evaluation always uses ALL rows of held-out data. Metrics AUPRC (base rate reported) and AUROC.
Directions: S1 leave-guide-out (5 folds of 2 guides): gate = M AUPRC >= best baseline + 0.02. S2 random row split vs cold-guide gap: gate = gap (random minus cold, M AUPRC) <= 0.05. S3 seed-vs-distal ablation: B2 using only PAM-proximal 10 nt mismatches vs only distal. S4 transfer CIRCLE-seq -> Kleinstiver and -> Listgarten GUIDE-seq (only 54 and 56 positives: wide uncertainty, stated). S5 label-shuffle control (M) plus negative:positive ratio sensitivity for B2 (1:1, 10:1, 50:1).
Not run: any 3D/chromatin feature; on-target activity; bulge-specific modelling.
